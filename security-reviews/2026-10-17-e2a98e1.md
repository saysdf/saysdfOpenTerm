# Security review: WezTerm base version e2a98e1 (2026-10-10)

- Review date: 2026-10-17
- Reviewer: Fable agent (read-only, no build or run)
- Scope: the whole tree (first download), submodules freetype2 VER-2-13-3, libpng v1.6.44, zlib v1.3.1, harfbuzz 11.2.1

## Verdict: SAFE WITH CAVEATS

No malicious code found. The repository and submodules match the official
upstream, and the build scripts do only what they claim. The caveats below are
long-standing upstream traits, not signs of compromise.

## Sources — OK

- `.gitmodules` points to the official repositories (`glennrp/libpng` is the old
  name; GitHub redirects it to `pnggroup/libpng`).
- Submodule commits match the tags exactly. The nested `dlg @ 72dfcc85` is
  exactly the gitlink recorded in freetype2 VER-2-13-3.
- There is no `rust-toolchain`; `.cargo/config.toml` contains only linker settings.

## Runtime surfaces

- **Update check** is enabled by default: once a day a GET to
  `api.github.com/repos/wezterm/wezterm/releases/latest` (`wezterm-gui/src/update.rs:40-64`).
  It only shows a notification and downloads nothing.
- **No telemetry.**
- **Opening URLs** happens only on user action (click, hotkey, `open_with`).
- **OSC 52**: writing to the clipboard is allowed, reading is ignored.
- **OSC 1337 File**: `allow_download_protocols = true` by default; a remote
  program can write a file to `~/Downloads`.
- **Plugins**: `wezterm.plugin.require(url)` clones an arbitrary git repository.
- **Mux and SSH**: local unix socket; TLS and SSH domains are empty; `mux_enable_ssh_agent = true`.

## Recommendations for the fork

1. Disable the update check (`check_for_updates = false` or the `distro-defaults` feature).
2. `allow_download_protocols = false`.
3. Decide what to do with the unsigned ANGLE, Mesa and MetalANGLE: rebuild from source
   or remove them together with the copying in `wezterm-gui/build.rs`.
4. Optionally: `mux_enable_ssh_agent = false`, review `hyperlink_rules`.

## What was NOT checked

- C/C++ code of the submodules and of the vendored cairo and pixman (only that they match the tags).
- Sources of about 800 transitive crates; `cargo audit` and `cargo vet` were not run.
- The ANGLE and Mesa hashes have nothing to be compared against.
- History deeper than 60 commits, and commit signatures.
- The Lua runtime and shell integration were only skimmed.
